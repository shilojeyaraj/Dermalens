## Setup Instructions:

### 1. Supabase Setup:
- Go to https://supabase.com
- Create new project
- Go to Settings > API
- Copy URL and anon key
- For service role key: Go to Settings > API > service_role key

### 2. Google Gemini AI:
- Go to https://makersuite.google.com/app/apikey
- Create new API key
- Copy the key

### 3. Google Custom Search:
- Go to https://developers.google.com/custom-search/v1/introduction
- Create new project
- Enable Custom Search API
- Create API key
- Go to https://cse.google.com/cse/
- Create custom search engine
- Copy the search engine ID

### 4. Elasticsearch:
- Download from https://www.elastic.co/downloads/elasticsearch
- Or use cloud service like Elastic Cloud
- Default URL: http://localhost:9200

### 5. OpenAI (Optional):
- Go to https://platform.openai.com/api-keys
- Create new secret key
- Copy the key

## Environment File Setup:
1. Copy variables above to .env file in apps/api/
2. Replace placeholder values with actual keys
3. Keep .env file secure and never commit to git

## Security Notes:
- Never share these keys publicly
- Use environment variables in production
- Rotate keys regularly
- Monitor API usage for unexpected activity
