# Dermalens Documentation

This directory contains all documentation for the Dermalens skin analysis application.

## Documentation Structure

### 📋 Status & Progress
- `status/` - Project status and completion reports
- `progress/` - Development progress and milestones

### 🚀 Setup & Deployment  
- `setup/` - Installation and setup guides
- `deployment/` - Production deployment documentation

### 🔧 Development
- `development/` - Development guides and technical documentation
- `api/` - API documentation and references

### 🎨 Frontend
- `frontend/` - Frontend-specific documentation

### 🔐 Authentication
- `auth/` - Authentication system documentation

### 📊 Features
- `features/` - Feature-specific documentation and guides

## Quick Start

When adding new documentation:
